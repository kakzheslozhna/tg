# Беседка в Telegram

Две части, обе работают от одного бота:

| | Где | Что умеет | Когда заработает |
|---|---|---|---|
| **Виджет** `widget.html` | прямо в сообщении (HTML-пузыри Telegram 13.2) | беседка в 3D, поворот свайпом вбок; тип, размер, материал; цену и состав считает бот полной моделью | когда Telegram откроет `sendWidget` (Bot API 10.4) |
| **Мини-приложение** `../index.html` | по кнопке бота, внутри Telegram | весь конфигуратор: 3D, расчёт, смета, раскрой | сразу после настройки |

Полный конфигуратор в пузырь не помещается. Лимит пузыря — 4 КБ кода после сжатия, у конфигуратора — 378 КБ. Ещё в пузыре нет WebGL и 3D-трансформаций.

Поэтому виджет — своя маленькая 3D-проекция на canvas 2D (3 КБ). Кнопка «Открыть в 3D полностью» запускает мини-приложение с той же конфигурацией.

## Настройка

1. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot`, затем имя. Сохраните токен — его нельзя никому показывать.
2. **Хостинг конфигуратора.** `index.html` нужно выложить по HTTPS: GitHub Pages, Netlify (перетащить файл на app.netlify.com/drop) или любой свой сайт. Страница будет доступна всем, у кого есть ссылка.
3. **Мини-приложение.** В @BotFather: `/newapp`, затем выберите бота и укажите адрес из п. 2. Короткое имя: `app`. Ссылка получится `https://t.me/<бот>/app`.
4. **Виджет.** Создайте `config.json`: `{"bot": "<имя бота без @>", "app": "app"}`. Затем выполните `python3 build_widget.py`. Сборщик проверит лимиты Telegram и сверит виджет с профилем песочницы: `python3 tools/check_profile.py`.
5. **Запуск бота** — на Mac или любом сервере с Node 18+:
   ```
   BOT_TOKEN=<токен> MINIAPP_URL=<адрес из п. 2> node bot/bot.js
   ```
   Бот ставит кнопку «Беседка 3D» в меню чата. На `/start` присылает виджет, а пока `sendWidget` закрыт — кнопку мини-приложения. На запросы виджета отвечает ценой из `../src/model.js`.

## Проверка без Telegram

- `node tools/preview.mjs <файл> 360 light|dark` — виджет в пузыре нужной ширины, с ответами настоящего бота.
- `node tools/miniapp_check.mjs <файл>` — `index.html`, открытый так же, как его открывает Telegram.
- `node tools/bot_check.js` — бот на имитаторе Bot API.

## Ограничения виджета (из документации TelegramMessenger/widget-sandbox)

- Размер: до 32 768 байт кода и 4096 байт после zlib-9.
- Пузырь: 200–600 × 50–600 px.
- Ресурсы: 8 МБ памяти, 300 мс процессора в секунду.
- Нет сети, полей ввода, WebGL и 3D-трансформаций.
- Вертикальный свайп всегда прокручивает чат, поэтому беседка вращается только по горизонтали.
- Отправлять виджеты может только бот: в личные чаты и группы, в каналы пока нельзя. Пересылать можно куда угодно.
